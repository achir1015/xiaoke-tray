# 小柯機器人3D托盤生成器　開發紀錄

開發者：吳玉柱 先生 與 Claude AI Opus 5.5　｜　期間：2026-11-18（一天內完成六個平台）

## 需求（使用者原話整理）

- 依 GitHub [TechnikWeber/Genstrio](https://github.com/TechnikWeber/Genstrio) 開發「小柯機器人3D托盤生成器」，參考 Bambu Studio MakerLab 裡的「Bento3D 參數化托盤生成器」操作方式。
- 平台：桌面版 Windows 11、MacBook Pro；線上版（HTML）；手機版 iPhone、iPad（要有線上安裝）、Android。先做 Windows，再逐一完成。
- 要有更新功能；圖示是小柯機器人＋3D 托盤，安裝要建立捷徑；要有語音動態教學。
- 開發途中補充：「可以在 Bambu Studio 工具內使用」。
- 資料夾 `E:\Bambu Studio外掛工具` 內的文案可以使用（裡面的 docx 是 Bambu Studio 網路外掛安裝失敗的排除說明，與本工具無直接關係）。

## 關鍵決策

| 問題 | 決定 | 理由 |
|---|---|---|
| 從零寫還是用 Genstrio | Fork Genstrio（AGPL-3.0），原樣保留 12 種產生器 | 已有真正的 CAD 核心（OpenCascade WASM）、STL／3MF／STEP 匯出；AGPL 要求公開原始碼 → GitHub repo 公開 |
| 托盤功能 | 另寫原創「便當托盤」產生器（`src/generators/build/tray.ts`），排首頁第一個 | Genstrio 的抽屜收納盒是「把抽屜切成很多盒子」，不是 Bento3D 那種單一分格托盤 |
| 介面語言 | 加入繁體中文 `zh` 並設為預設 | 1195 條字串分 4 份由子代理翻譯，再用腳本檢查 key 與 `{佔位符}` 一致 |
| 「在 Bambu Studio 內使用」 | 做「送到 Bambu Studio」一鍵按鈕 | Bambu Studio 沒有開放第三方外掛介面（MakerLab 是拓竹自家網頁）；改成產生 3MF 後直接用 bambu-studio.exe 開啟 |
| 桌面框架 | Electron 33＋自訂協定 `xktray://` 載入 `dist/` | wasm 與 module Worker 都能用；不用固定埠 |
| 手機 | iOS：WKWebView＋App 內 127.0.0.1:48291 小伺服器；Android：WebView＋`appassets.androidplatform.net` 攔截 | 沿用小柯陸軍棋（xiaoke-junqi）已驗證的外殼 |
| 手機存檔 | iOS 用分享選單（存到檔案／AirDrop）；Android 存「下載／小柯托盤」 | 手機上沒有 Bambu Studio |
| 版本 | v1.0.0 Windows → v1.1.0 加 Mac → v1.2.0 加 iPhone／iPad；Android APK 掛在 v1.2.0 | Android 只改了手機專用程式路徑，不影響其他平台，所以沒升版 |

## 過程（依時間）

1. **分析與建置環境**：clone 上游到 `genstrio-upstream/`（參考用，不進 repo），複製成 `xiaoke-tray/`。上游是 Vite＋TypeScript＋replicad＋three.js，需 Node ≥ 20.19 → 用 nvm 的 Node 22。原樣 `npm run build` 成功。
2. **繁中化**：把 `src/i18n.ts` 英文字典拆 4 份平行翻譯 → `i18n-work/check.cjs` 驗證 0 錯 → `assemble.cjs` 併入。踩坑：原始檔是 CRLF，要先轉 LF；`stage.hollow` 與上游重複 key 要刪。
3. **便當托盤產生器**：寬深高、壁厚、底板、圓角；平均分格或比例分格；隔板高度／厚度；可堆疊底腳（縮一圈＋配合間隙）；指扣；標籤斜台；底板鏤空。8 個範本。`tests/tray.test.ts` 10 項，全部測試 132 項通過。
4. **品牌與圖示**：`scripts/make_icon.py` 畫小柯機器人＋藍色 2×2 托盤（托盤用 13×13 柱體依前後順序畫，避免面重疊錯誤），輸出 `build/icon.png/.ico` 與網頁用 PNG。主色改藍色、模型改 Bambu 風格藍。
5. **語音動態教學**（`src/xiaoke.ts`）：13 步；聚光框框住目標、小柯機器人說話動畫、邊講邊示範（改寬度、分格、堆疊、指扣、範本）。踩坑：表單裡的框要裁到可見範圍；某些語音引擎 cancel 後不觸發 onend → 自己記住 `cutSpeech` 直接結束；切換步驟間按關閉的競態要在說話前再檢查一次。
6. **Windows 桌面版**：`electron/main.cjs`（協定、視窗記憶、下載存「文件\小柯托盤」）、`bambu.cjs`（從登錄檔 DisplayIcon 找 bambu-studio.exe → 存 3MF → 啟動）、`updater.cjs`（沿用小柯接龍）。`e2e/desktop.mjs` 透過 CDP 測 12 項＋`--bambu` 實際送進 Bambu Studio 成功（檔案在 OneDrive 的文件資料夾）。NSIS 安裝檔＋免安裝版，靜默安裝建立捷徑。
7. **公開 GitHub**：建立 `achir1015/xiaoke-tray`，發佈 v1.0.0。隱私外掛擋下 commit 作者 email → 改用 noreply 信箱、package.json 不放 email、重建安裝檔再上傳。上游的 Pages workflow 先改成手動。
8. **Mac 版（v1.1.0）**：抄小柯陸軍棋的 ad-hoc 簽章（`build/adhoc-sign.cjs`）與 `.github/workflows/build.yml`（推 package.json 版本即建 win＋mac-arm64＋mac-x64 並發 Release）。Intel MacBook Pro 實機 15 項（含送 Bambu Studio）通過。Windows 程式內更新 1.0.0→1.1.0 實測成功（靜默更新會改裝到 `C:\Program Files\XiaokeTray`）。
9. **線上版**：`pages.yml` 推 main 自動部署到 GitHub Pages；綠色按鈕改「下載 3MF」、首頁加桌面版下載連結；更新比對 `version.json`。使用者曾在 GitHub 網頁改 README → 推送前要 `git pull --rebase`。
10. **iPhone／iPad（v1.2.0）**：`ios/`（XcodeGen）；`public/ios/` 安裝頁（itms-services＋QR）由 vite 複製到 `dist/ios`。在 Mac 用 Terminal 執行 `build-ipa.sh`（SSH 進去鑰匙圈是鎖的）。iPhone 15 Pro Max 以 devicectl 安裝；模擬器截圖確認 CAD（105 ms）與教學正常；使用者自行在 iPhone／iPad 實測完成。
11. **Android**：`android/`（無 Gradle 的 `build.py`）；存到「下載／小柯托盤」、系統 TTS 語音教學、APK 更新、返回鍵。SM-S9380（Android 17）`e2e/android.mjs` 15 項通過。踩坑：手機按允許後 adb 仍 unauthorized → `adb kill-server` 再 `start-server`。

## 待辦／可延伸

- Android 金鑰 `android/xiaoketray.jks` 只在本機，請另外備份（遺失就無法覆蓋安裝）；也可放進 GitHub Secret 讓 CI 建 APK。
- iOS／Android 目前要手動建置上傳；可比照其他小柯專案改成 CI。
- 托盤可再加：側壁鏤空花紋、蓋子、標籤文字直接雕刻在托盤上。
- Mac 版沒有 Apple 公證，其他 Mac 第一次開啟要右鍵「打開」。
